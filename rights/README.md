# 来源登记与发布检查

## 当前范围

本次审查当前默认分支的 Markdown、Python 校验脚本、配置和许可证文件。尚无正文图像、截图、字体、实验数据集、完整上游源码副本或编译产物，未来引入时另行审查。Git 历史中的旧材料不因当前修订自动获得新增授权。

基线之后本项目新增且有权授权的讲解采用 CC BY-NC-SA 4.0，新增代码采用 Apache-2.0；第三方材料排除在默认授权之外，按原许可或具体使用依据处理。来源见 [sources.json](sources.json)。

## 准入步骤

1. 区分自行编写、外部引用、改编、翻译、截图和生成辅助内容，不能只凭文件由本项目创建就认定拥有全部权利。
2. 登记作者或权利人、标题、地址、具体版本、许可及证据、使用位置、复制范围、修改与翻译情况。
3. 保留必需的版权、许可、NOTICE 和修改说明，不删除原作者信息，不暗示背书。图片、字体、品牌和界面元素单独判断。
4. 来源或使用依据不清时标为待核实，不复制进可发布书稿。仅引用已公开作品不自动满足全部法律条件。
5. 审查后在正文、图注或代码旁放置相应署名与许可，保留权限证据；授权材料中的个人信息只公开必要部分。
6. 发布前人工复核全部实际纳入材料、编写方式说明与适用平台标识规则。

## 资产登记

图片、字体、PDF、音视频等资产在 `sources.json` 的 `materials` 中按路径登记 `source_id`、`basis`、`status`。状态为 `cleared` 才能通过资产检查；自行创作也记录制作依据及是否包含第三方素材。

改变配色、重新绘图或用工具生成相似图不能直接认定独立创作。软件截图可能包含另行保护的内容，开源许可不自动授权其中所有元素。

## 检查及限制

运行 `python tools/check_licenses.py` 检查许可文本指纹、来源记录、版权声明和资产登记；运行 `python tools/verify_book.py` 检查链接与活动文件指纹。清单按实际审核更新，不为通过检查伪造许可状态。

脚本不能判断实质相似、适当引用、授权人权利、著作权归属或全部地区的法规适用。这些仍需人工审核；有争议时暂停相关材料发布，再核实处理。

新旧许可分界以 rights/prior-publication.json 及其基线 Git 版本为准。新限制只适用于新增且有权授权的表达；既有宽松许可、第三方权利、法定例外和代码许可不受追溯限制。
