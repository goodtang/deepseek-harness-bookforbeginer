# 教材共享约定

当前权威要求为 [V6](../planning/book-plan-v6.md)。此文件仅记录高频约定与来源；与 V6 冲突时先核对并纠正执行记录。

- 读者为零基础学生，基础知识在依赖前解释；不能把见过配置等同已理解。
- 一切皆插件贯穿全书；普通函数、库、插件及独立教学循环分别标记。
- 主线为企业问题处理助手，先只读查询，再控制写入与协作，最后交付应用。
- 每章保留预测、作者实测、学生复现、差异解释与结论；第三方报告独立标记。
- 配图有来源、简化范围与图例，图、代码、正文及实验版本对应。
- 连续三章验证在 M1 后、M2 批量扩写前，不阻塞第一篇闭环样章产出。
- 用户希望达到渐进、自学、独立编程和阅读陌生实现的教学效果，不构成一周掌握的承诺。
- 源码研究基线为 `fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159`；实际任务启动时仍须核对工作树。

尚未确定：工单固定数据、查询函数正式符号、工具正式名称与字段、实验路径及命令。E1 依据实际工程确定后记录定义位置与影响章节，不在后续正文中自行假设。

- 正式教材维护仓库为 goodtang/deepseek-harness-bookforbeginer；原业务仓库中的 artifacts 为导入来源，后续不双向维护。
- 首读者候选为 goodtang，候选身份不等于已同意参与、独立完成或读者验收通过。

版权规则已分为基线之后新增且有权授权的正文/自制图 CC BY-NC-SA 4.0、代码 Apache-2.0、第三方按原许可；历史 Apache-2.0 与 CC BY 4.0 授权保留。新增许可文本、来源登记、第三方署名与编写方式说明，后续按 rights/README.md 审查素材。正文与实验验收仍未完成，不将版权文档更新视为教材实测通过。

新旧许可分界以 rights/prior-publication.json 及其基线 Git 版本为准。新限制只适用于新增且有权授权的表达；既有宽松许可、第三方权利、法定例外和代码许可不受追溯限制。
