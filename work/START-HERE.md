# 教材工作接续入口

读取顺序：当前用户指令与适用 AGENTS → [STATE](STATE.md) → [HANDOFF](HANDOFF.md) → [CANON](CANON.md) → [CHAPTERS](CHAPTERS.md) → 当前工作包及相邻原文。

总体要求见 [V6](../planning/book-plan-v6.md)，执行方法见[实施安排](../planning/execution-plan.md)。新增聊天应由用户或调用方提供本文件路径；不能假定它会自动载入。

先确认本轮唯一交付物与未完成检查，再继续。工作记录中的摘要是导航，不能替代正文、源码或实验原件。

[FILES.json](FILES.json) 保存经审查的活动文件 SHA-256，供识别版本变化；它不是实时监控。后续不一致时先核对变更与记录，审查差异后按实施规则刷新指纹。
