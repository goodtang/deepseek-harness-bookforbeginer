# 教材工作接续入口

读取顺序：当前任务要求与适用 CONTRIBUTING → [STATE](STATE.md) → [HANDOFF](HANDOFF.md) → [CANON](CANON.md) → [CHAPTERS](CHAPTERS.md) → 当前工作包及相邻原文。


当前编写依据见 [V6](../planning/book-plan-v6.md)、[实施安排](../planning/execution-plan.md)与[贡献指南](../CONTRIBUTING.md)。

先确认本次工作唯一交付物与未完成检查，再继续。工作记录中的摘要是导航，不能替代正文、源码或实验原件。

[FILES.json](FILES.json) 保存经审查的活动文件 SHA-256，供识别版本变化；它不是实时监控。后续不一致时先核对变更与记录，审查差异后按实施规则刷新指纹。
