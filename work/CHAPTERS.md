# 初始章序与依赖索引

以下 ID 用于最先实施的连续片段，与最终出版章号无关。其余章节在实际进入对应篇时登记，不预造已经完成的正文路径。

## 状态记录规则

本文件是章节状态的统一索引，工作包保留具体证据，STATE 只概述全书进度。正式编写每章前先建记录，每轮收尾同步更新；没有新证据时不自动推进状态。出版章号未确定时保留稳定 ID，不把 CH-TOOL 样章标为第一章。

写作状态依次记录为“待写、试写、正式初稿中、初稿完成、修订中、定稿”。试写转正式初稿必须明确记录纳入范围，并复核前置知识与章间衔接；已有三段试写不等于整章初稿完成。“定稿”要求技术、图稿、连贯性和读者验收均满足该章要求，不能仅凭字数或作者自评推进。

技术、图稿、连贯性、读者验收各自记录“未检查、部分通过、通过、失败、待复核”，附范围与证据；无运行实验的章节按适用推导或演算验收，标明不适用项及理由。这些检查可分别推进，不能用实验通过代替读者通过。读者未实际参与时保持未检查。

每章记录：稳定 ID、正式章号（未定则留空）、正文与工作包路径、写作状态、已完成和待完成小节、四类检查状态及证据、适用源码/正文版本、更新日期、下一步。正文、代码、图或前置章节改变后，将受影响检查改为待复核，旧证据保留适用版本。
