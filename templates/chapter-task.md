# 章节工作包模板

本文件是创建实际章节工作包的模板，字段未填不代表工作已执行。

## 任务与资料范围

开写前记录稳定章节 ID、正式章号（未确定则留空）、正文路径、写作状态、已完成/待完成小节、技术/图稿/连贯性/读者四类检查状态及证据、适用源码与正文版本、更新日期和下一步。字段及状态含义以 work/CHAPTERS.md 为准。每轮收尾更新索引，试写不能直接登记为正式章节完成。

填写章节 ID、本次工作唯一交付物、所属阶段、当前状态。列出上一章、当前章、下一章的路径和读取范围；尚无正文时标明仅有交接目标。记录相关远处定义及为何必须读取。

## 章间交接

记录进入状态、输入产物、新问题、新增知识、暂不展开及回访位置、输出产物、检查补救、下一章入口。每项知识能定位到首次解释和检查。

## 版本与依据

记录代码提交与工作树、未提交正文/图/示例的路径及 SHA-256、关键源码符号与坐标、实际配置。列出本次工作开始时读取的版本，区分历史证据与当前证据。

## 实施与检查

记录具体修改、配图、输入输出和断言。分别标明写好、未运行、运行通过、运行失败、待复核；不得将模型答复、退出 0 或另一任务的报告代替当前行为证据。

## 一致性复核

核对前章输出可被本章使用、本章前置已讲、术语与图一致、代码逐章演进、业务目标未遗漏。变更影响列出所有依赖章节，不仅相邻章节。

## 收尾交接

链接交付物与证据，列出未运行检查、未解决问题、自有进程及清理状态，指定下一项实际操作。更新 STATE 与 HANDOFF，保留历史原件和适用版本。

每轮可推进 1–3 个相邻小节，但须围绕同一教学目标。收尾记录章内和前后段落连贯复核；读者反馈区分独立完成、提示后完成、讲解后完成及未完成。

## 来源与权利记录

本章使用的每项外部文字、代码、图片、截图或数据，记录来源 ID、作者/权利人、具体版本、许可或引用依据、位置与范围、修改/翻译说明。第三方声明放在引用处并关联来源清单；图源自行创建也检查是否改编自受保护材料。未知权利项目保持待核实，不进入发布稿。自行撰写内容与第三方材料许可分开标记；不得把参考书的例题、图文或独创编排当作本书自由许可内容。
