# 第一章配套：观察一次任务

本实验给[第一章](../../chapters/CH-OBS.md)提供真实运行后的观察记录。没有开发环境的读者可以先使用[本轮输出](evidence/observation.txt)完成观察练习；这不等于已经独立复现。下一章将专门讲文件、路径、命令与环境准备，本页是已有环境时的运行参考。

## 运行准备好的实验

已经准备好源码与依赖时，在书稿仓库目录打开 PowerShell：

```powershell
node labs/observe-task/run.mjs D:/projects/deepseek-harness-local
```

`node` 是运行 JavaScript 程序的命令；`labs/observe-task/run.mjs` 是相对于书稿仓库目录的脚本路径；最后一项是源码仓库的绝对路径。源码位置不同就替换最后一项；路径含空格时使用双引号。示例不需要真实模型密钥。

默认把当前运行的 `run-evidence.json`、`observation.txt`、`observation.json` 写入本实验的 `.lab-runtime` 目录，该目录被 Git 忽略。输出最后一行给出实际位置。不要把它与 `evidence` 中已经发布的实测记录混为同一次运行。可选的第二个参数指定输出目录，仅供教材取证或明确需要另存的运行使用。

作者本轮条件为 Windows、Node v24.12.0、源码提交 `fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159`，源码已跟踪文件无变更且依赖预先就绪。源码要求 Node >=24.9.0。未在新机器重建依赖，也未在其他平台运行；不能把本轮成功记成全平台安装已验证。

## 执行和证据

[run.mjs](run.mjs) 调用已有[真实工具实验](../first-tool/README.md)。2026-11-11 为底层运行器补充实际任务、捕获的调用与终端 stdout 记录，插件和工单数据未改。内部仍通过支持的 dsh headless profile 使用真实工具注册及执行管线。观察程序仅在底层实验退出成功后，核对本次字段和代码哈希，再输出摘要。摘要在结束后生成，不是实时事件流，也没有新增 Harness 事件类型。

模拟模型严格按 `tool_call_success,success` 回应，不重复末条；工单是固定虚构数据。底层实验显式关闭自动标题生成，并用临时 home 与工作目录隔离。源码启动仍显式指定该检出的 tsconfig，避免工作目录改变导致源码包解析不同。既有实验参数、原理和限制以其说明为准，本页不再复制一套实现。

当前发布证据在 evidence/2026-11-11；原 evidence 根目录记录是 2026-11-10 版本，仍保留原始代码哈希和内容。默认复现始终写入忽略目录，不覆盖上述已发布原件。新脚本不应借旧记录跳过当前检查。

## 差异与失败

如果提示找不到脚本，先检查当前目录是否为书稿仓库；找不到 `package.json` 或 `tsx` 时，检查最后一项是否指向依赖已就绪的源码仓库。准备工作未完成就保留“待复现”，不要改脚本绕过。底层实验退出非零时，本次观察运行器也退出非零，不会读取旧成功文件来宣布当前运行通过；失败原因优先查看终端和本次底层证据。

底层的真实 headless 子进程有 90 秒截止，正常收尾关闭 mock，删除自有临时目录。输出证据目录保留，便于读者对照；它不同于已删除的应用临时 home。断流恢复和主动取消尚不在本场景内，不将异常退出后的全部资源行为记为已验证。

本轮正常场景已实测通过，读者复现未验收。模拟服务没有连接真实模型或真实工单系统；没有进行断网隔离验证。本目录独立可执行代码为 Apache-2.0，图文按本仓库现行范围授权，所用上游接口及其源码仍受 DeepSeek 原 MIT 许可保护。
