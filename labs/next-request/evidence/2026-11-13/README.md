# 第五章定点修订的作者证据

render-comparison.json 来自三个真实 profile 运行的事后比较：完整展示、修改插件为摘要、精确恢复。每份都核对采样到的 render 输入、实际持久结果及第二请求内容；业务值保持三字段，展示按三/二/三字段变化。调用均由真实工具管线执行，未伪造模型请求或重写历史。

起点在 ../../start/plugin.mjs；summary-plugin-source.txt 保存中间那份实际运行插件的完整字节，摘要比较记录包含插件哈希，原工作层级为 .lab-runtime。它是供读者核对的源码快照，复制回该层级并命名为 .mjs 后再运行，不直接把证据目录当插件工作目录。完整本机原件存于 .lab-runtime/final-full、final-summary、final-restored；公开摘录不包含完整系统提示和请求上下文。

checks.json 是修订后 inspect/check 对新正常原件的核对，含代码指纹；此前日期的检查只对应旧版本。revision-verification.json 记录当前代码、三次对照、原 S1/S2/S2-exhaust/S3 回归，以及故意停住模块加载的诊断反例。该反例应退出失败并报告 watchdogExpired=true，不能按正常 S1 通过。

作者在修订前遇到的一次零请求超时没有足够诊断信息，随后原命令复跑通过。新增阶段记录可帮助继续定位；故意停住模块加载只证明诊断反例有效，不证明原超时根因。早期试验文件未移作通过证据，旧记录保持各自范围。

以上均为作者核验，读者独立完成、外网隔离、新机、其他平台和图稿发布检查仍待完成。
