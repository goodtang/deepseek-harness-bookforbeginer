# 第六章修订与启动复核

verification.json 是本轮五组普通模式真实运行的核对：解除等待、合作取消、关闭监听、恢复、结果提交后取消，六项错误副本均拒绝。输入来自 .lab-runtime/revision-20261118-final-*，不是覆盖13日原件或把旧结果改记为今天成功。

diagnostics.json 分开列出先前两次零请求超时、五项诊断对照和当前八组普通模式回归。导入追踪会改变加载时序，成功不构成旧超时根因证明；无追踪和显式配置禁用转译缓存的对照也完成了启动，目前仍未定位根因。没有提高45秒限制或自动重试失败。

旧探针只记录一次预加载，不具备心跳功能，不能根据那些旧文件缺少心跳判断线程阻塞。新探针的三个进程测试输出见 startup-probe-tests.txt，检查不延长进程生命周期、运行中心跳和显式追踪开关。诊断文件记录新旧探针哈希，完整导入地址和请求提示仅留本机/私有原件；公开摘要只保留必要状态、数量、时间和输入哈希。

正文新增step传出signal的源码连接，以及与实际起点一致的try/finally核心和三路执行顺序。仍是作者核验，不签收读者或关闭原超时问题；图稿页面/PDF、外网隔离及其他列明范围保持待验。
